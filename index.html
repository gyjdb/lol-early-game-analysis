01 / Findings

Team strength changes the benchmark.

A stronger team should already be expected to win more often from the same 20-minute state.

01 · Prediction

3.3% lower Brier

State + prior Elo improves on gold + side in the chronological evaluation. Against state alone, ΔBrier is -0.00305; the cluster interval is below zero.

02 · Trajectory

More features ≠ better forecasts

Adding 15→20 changes to state + Elo worsens Brier by 0.00195. This is a result about these linear models and this sample, not proof that momentum never matters.

03 · LPL

High conversion can be expected

BLG wins 53/62 held-out leading games. The model expected 52.9 wins: an adjusted residual of only +0.09 pp. Raw conversion alone would overstate the surprise.

03 / The next five minutes

What happens to a 20-minute lead?

Track the observable transition before trying to explain the decision that caused it.

Future state is an outcome here, never an input to the 20-minute prediction. A lead shrinking does not by itself identify a bad Baron call, a lost vision contest, or a draft scaling disadvantage.

2,161 of 2,302 source games pass paired completeness and 15/20-minute feature checks. LPL: 535/674 (79.4%). Coverage refers to the downloaded source, not an independently verified tournament census. Snapshot retrieved 13 September 2026; September is incomplete.

What the benchmark knows

Gold, XP, CS and kill differences at 20 minutes, map side and league-local pre-day Elo. Elo starts every team at 1500 in January, uses fixed K=20, and updates only after the day ends. Available results from excluded snapshot games can update Elo.

What it cannot identify

No final objective, vision or plate totals enter the model. No roster adjustment, explicit patch effects, validated draft scaling model or replay annotations. Elo is a rough strength proxy. Missing games, changing rosters and patches limit interpretation.
